## Rebuild everything

```powershell
python scripts/make_report_assets.py          # diagrams and charts from real project data
python scripts/launch.py --no-browser --port 8502   # app for screenshots
python scripts/capture_screens.py http://localhost:8502   # real screenshots (AI coach uses the real model)
python scripts/eval_ai_coach.py               # real-model evaluation table
# then, with the docx and pptxgenjs npm packages available (NODE_PATH):
node deliverables/build_report.js ; node deliverables/build_notes.js ; node deliverables/build_updated_deck.js
```

The raw full-page screenshots are not committed (they are regenerated by `capture_screens.py`); the cropped parts used by the documents are in `assets/screens/parts/`.
